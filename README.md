# 딸기로 AI 에이전트 가이드 (`ddalgiro-ai-agent`)

딸기로컴퍼니의 **AI 에이전트를 처음부터 구성하는 방법을 모은 저장소**입니다. 문서와 함께, 문서가 쓰는 매니페스트·스크립트·에이전트 소스가 들어 있습니다.
[딸기로 가이드 `ddalgiro-guide`](../ddalgiro-guide/README.md)에 딸린 프로젝트이며, 가이드·6개 구현 프로젝트와 같은 규칙으로 관리합니다.
프로그래밍을 처음 하는 사람도 순서대로 읽고 따라 할 수 있게 쓰는 것이 목표입니다.

현재는 **시제품을 구성하는 가이드**입니다. 로컬 시험과 코드 대조를 마쳤지만, 실제 AWS·Claude API 연결과 정식 성능 평가는 아직 확인하지 못했습니다. 각 문서 머리의 확인 범위와 [남은 작업](PROJECT_STATE.md#다음-작업)을 함께 봅니다.

| 만드는 것 | 내용 |
|---|---|
| 서버와 모델 | AWS EC2 한 대(`t3.xlarge` · 16GB)에 K3s를 올리고, 대화 모델은 Claude API를 부릅니다. 이중화 없음. 사무실 GPU 장비(DGX Spark)는 [추후 도입](docs/08-추후-도입/01-DGX-Spark-도입.md) |
| 기능 | 연구개발계획서의 두 안건 — [트렌드 분석·추천](../ddalgiro-tips-task/docs/02_트렌드분석추천시스템_기획.md)과 [단체주문 자연어 추천·랭킹](../ddalgiro-tips-task/docs/03_자연어추천랭킹시스템_기획.md). 구현 범위는 [대응 문서](docs/00-개요/03-연구개발계획서-구현-대응.md) |
| 쓰는 곳 | 딸기로 관리자 화면 — 직원이 입점업체에 줄 AI 정보를 봅니다 |
| 공개 | AWS 보안 그룹과 IP 허용 목록으로, 딸기로 백엔드만 HTTPS로 부릅니다 |

## 검사

이 저장소 폴더에서 실행합니다.

```bash
npx --yes markdownlint-cli2 "**/*.md" "#node_modules" "#agent/.venv"
node ../ddalgiro-guide/tools/check-mermaid.mjs .
for f in scripts/*.sh scripts/*/*.sh; do bash -n "$f" && echo "문법 OK: $f"; done
```

- 첫 줄은 마크다운 서식을 검사합니다. 오류 0건이면 통과입니다. 설정은 `.markdownlint.json`입니다.
- 둘째 줄은 Mermaid 도식 문법을 검사합니다. `실패 0개`가 나오면 통과입니다. 가이드 저장소의 검사 도구를 함께 쓰므로 `ddalgiro-guide` 폴더에서 `npm install`을 한 번 해 두어야 합니다.
- 셋째 줄은 셸 스크립트의 문법을 검사합니다.
- 에이전트 소스의 시험은 [에이전트 구조와 배포 5장](docs/04-에이전트/01-에이전트-구조와-배포.md#5-코드를-고쳤을-때)에 있습니다.
